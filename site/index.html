Kalshi demo dashboard

Live, read-only tracking of the highest-volume Kalshi markets in five topics — gas prices, elections, culture, crypto and golf — with every value linked to the official API endpoint it came from. Values that the API does not return are shown as UNVERIFIED, never estimated.

Executive summary

  • What this is. A static site built from public, unauthenticated Kalshi Trade API GET requests. A scheduled GitHub Actions job refreshes the snapshot hourly and redeploys GitHub Pages. No orders are placed and no credentials are used. Sources: Demo environment · Get Markets.
  • Demo is not a real market. Kalshi's own demo documentation says the price and behavior of markets in the demo environment may not be reflective of those in real markets and that demo uses mock funds. The dashboard therefore shows both the demo API and the read-only production API side by side. Source: Demo environment.
  • Demo liquidity is thin. Most demo open markets show zero traded volume, and the top-volume demo market on the first 1,000-market page that was read (KXDEMOFUTHOURLY-…) carries a DEMO ticker. See Flagged for Review.
  • Resolution is tracked. Settled markets are shown with the official result field (yes / no). Kalshi documents that a YES outcome pays $1 per YES contract and a NO outcome pays $1 per NO contract. Source: Market Settlement.
  • Price charts have limits. The REST candlestick endpoint offers 1-minute, 1-hour and 1-day periods only. Second-level history needs the WebSocket feed, which this static site does not run. Source: Get Market Candlesticks.
  • Liquidity is shown as bids. Kalshi returns only bids. The YES ask is implied as $1.00 minus the best NO bid. Source: Orderbook Responses.
  • Portfolio and trading are blocked. Reading a portfolio or placing trades requires an authenticated API key for the demo account. None has been provided, and this build does not create one. No trades have been placed. See Portfolio & trades.
  • Strategy findings are hypotheses. The Analysis page computes descriptive statistics from the snapshot. It does not show a demonstrated edge.
  • Decisions needed before any change. Review the Suggestions board and the Questions & information gaps list. Nothing will be implemented until you choose a path.
