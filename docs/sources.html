Sources — Official Documentation Used

Every factual claim on this site traces to one of these official pages (all verified 2026-11-20 by fetching the page content and checking it line by line against the code). Anything not in this table is either live API data (fetched in your browser, never transcribed) or a clearly labeled analytic convention/proposal.

#Official pageWhat it confirms (used for)
S1Test In The Demo EnvironmentDemo REST root https://external-api.demo.kalshi.co/trade-api/v2, also-supported https://demo-api.kalshi.co/trade-api/v2, demo WS wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2; demo site https://demo.kalshi.co/; mock funds; demo credentials separate from production; demo prices may not reflect real markets.
S2API Environments and EndpointsProduction vs demo base URLs; signing covers the full URL path from the API root, without query string.
S3API KeysKey types (Ed25519 recommended, RSA 2048-bit); headers KALSHI-ACCESS-KEY, KALSHI-ACCESS-TIMESTAMP, KALSHI-ACCESS-SIGNATURE.
S4Quick Start: Authenticated RequestsSignature message = timestamp + METHOD + path, timestamp in milliseconds, path = full path from root (e.g. /trade-api/v2/portfolio/balance) without query; RSA keys: RSA-PSS SHA-256 (salt = digest length); Ed25519 signs the message directly; balance returned in cents (balance / 100); /portfolio/balance, /portfolio/positions, /portfolio/orders endpoints; timestamp must be within 30s of Kalshi's clock.
S5Quick Start: Create your first orderPublic market data needs no auth (GET /markets?limit=1&status=open); POST /portfolio/events/orders body fields exactly: ticker, side ("bid"), count (string), price (dollars string, e.g. "0.0100"), time_in_force ("good_till_canceled"), self_trade_prevention_type ("taker_at_cross"), client_order_id (UUID); 201 + remaining_count (accepted ≠ filled); client_order_id dedup rules (64 chars from _ - : + = / and alphanumerics).
S6Get MarketsGET /markets params: limit, cursor, event_ticker, series_ticker, status (unopened/open/paused/closed/settled), min/max timestamp filters; cursor paging rules; responses cached (can lag seconds); settled-before-cutoff markets live under /historical/markets.
S7Get MarketFull Market schema: yes_sub_title (canonical; title deprecated), status enum (initialized…finalized), result enum (yes/no/scalar/""), yes_bid_dollars etc. as fixed-point dollar strings, volume_fp / volume_24h_fp / open_interest_fp as contract counts, settlement_ts (settled markets only), settlement_value_dollars, notional_value_dollars = settlement value of one contract (not a volume measure), rules_primary/rules_secondary, price_ranges tick grid.
S8Get Series ListGET /series params: category, tags, include_product_metadata, include_volume, min_updated_ts (no documented limit/cursor); Series fields: ticker, title, category (primary), categories[] (discovery list), tags[], frequency, fee fields. Used for live topic discovery.
S9Get Market CandlesticksGET /series/{series_ticker}/markets/{ticker}/candlesticks, params start_ts/end_ts (Unix seconds) and period_interval ∈ {1, 60, 1440} minutes; OHLC nested under yes_bid/yes_ask/price with *_dollars strings.
S10Batch Get Market CandlesticksGET /markets/candlesticks (used by this site's charts), params market_tickers (comma-sep, ≤100), start_ts/end_ts, period_interval (minutes, ≥1), optional include_latest_before_start; response {markets:[{market_ticker, candlesticks:[{end_period_ts, price:{close_dollars,…}, yes_bid, yes_ask, volume_fp, open_interest_fp}]}]}; ≤10,000 candlestick periods per request.
S11Get Market OrderbookGET /markets/{ticker}/orderbook → orderbook_fp.yes_dollars / no_dollars: arrays of [price, size] (fixed-point dollars / contract counts); yes bids and no bids only; depth param 0–100. Used for the liquidity card.
S12Orderbook ResponsesBinary-book mechanics: a yes bid at price X is equivalent to a no ask at 1−X, which is why only bids are returned.
S13Fixed-Point Representation*_fp contract quantities = strings, 2 decimals, min granularity 0.01 contracts ("1.55" = 1.55 contracts); *_dollars prices = dollar strings up to 4–6 decimals; price_ranges is the source of truth for valid prices. Basis for every unit label on this site.
S14Market LifecycleStatuses initialized/active/inactive/closed/determined/disputed/amended/finalized and transitions; result set at determination; settlement timer settlement_timer_seconds.
S15Market SettlementYes holders receive $1/contract on Yes resolution, No holders $1 on No; net positions only; settlement fees zero for simple yes/no.
S16Get FillsGET /portfolio/fills; Fill schema: outcome_side ('yes'/'no') + book_side ('bid'/'ask') canonical, legacy side/action deprecated; count_fp, yes_price_dollars/no_price_dollars, fee_cost = fixed-point dollars, created_time, is_taker; pagination limit/cursor; pre-cutoff fills via /historical/fills.
S17Get PositionsGET /portfolio/positions — unsettled positions by default, incl. closed markets awaiting determination.
S18Get SettlementsGET /portfolio/settlements — settlement records; the discovery path for the outcome-joined P&L idea (Suggestion S4).
S19Create Order (V2)Confirms the V2 event-market order shape; the legacy /portfolio/orders write endpoints return 410 Gone — this site uses /portfolio/events/orders only.
S20Kalshi Fee Schedule (official PDF)Series-ticker examples used only as reference labels: KXAAAGASM (US gas price), KXPGATOUR (PGA Tour), KXPGARYDER (Ryder Cup), KXPGASOLHEIM (Solheim Cup). Fee amounts are not reproduced.

What is deliberately NOT here

No static market prices, volumes, balances, or resolutions — those change constantly and are only ever fetched live in your browser (or via scripts/kalshi_client.py against the demo API with your own keys). No table on this site transcribes a live value into the repo. Any value that could not be confirmed from an official source is left blank and listed on Flagged for Review.
