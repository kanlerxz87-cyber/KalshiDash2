Trade analysis & strategy catalogue

Two separate things live on this page: your demo fills, categorised by topic, side and maker/taker role; and a catalogue of strategies expressed as rules over fields the API actually returns, so each one can be tested against real fills later.

How categorisation works

Each fill carries a market ticker. The ticker is mapped to one of the five topics by looking up its event and applying the same category rules the dashboard uses — no ticker is hardcoded. Fills whose event is outside the five topics are counted as outside scope, not silently dropped.

Strategy catalogue

Every strategy is written as a rule over API fields. A strategy only becomes "tested" when enough real fills exist; until then it is marked untested rather than claimed to work. Each entry names the evidence needed to evaluate it.
