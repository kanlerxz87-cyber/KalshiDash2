Verification — evidence for every claim

Three kinds of row appear here. Documented rows are checked against Kalshi's own documentation. Observed rows are checked against the JSON in docs/data/, which records the URL each value came from. Anything that could not be checked is left blank and marked unverified — it is never filled in.

Claim checks

Snapshot provenance

Every file under docs/data/ records the request that produced it. This table is generated from those files, not typed by hand.

Live API probes

These run in your browser against the public demo endpoints. If your browser blocks the request (no CORS header), the row says "blocked", which is itself a result — it is recorded rather than hidden.

What is deliberately not shown

  • No specific balance, position or fill — those need an account key that must not exist in this repository.
  • No forecast, projection or expected value. This site reports what the API returned.
  • No number derived from a field that the API did not return. A dash means "no value", not zero.
  • No production price shown as if it were a demo price, or the reverse.
