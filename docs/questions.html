What is still missing from this project

Real account history No demo account credentials exist in this repository, and none should. Every portfolio number is blank until you add a key in your own browser. Anything else would be invented.
Second snapshot Change-over-time metrics (price moves, new top markets, resolutions since last run) need at least two snapshots 15 minutes apart. The first snapshot cannot show a delta.
Gasoline-specific markets The exchange taxonomy has "Oil & Gas" under Commodities but no gasoline/pump-price bucket. See Flagged F-GAS for the exact query used and what came back.
Sub-minute price history The public REST API exposes 1-minute candles at the finest. A seconds chart requires either authenticated WebSocket streaming or repeated polling from the browser, and both need an API key.
Which of the two demo hosts is canonical Kalshi documents one as recommended and the other as "also supported". The collector uses the recommended host and falls back to the other only after a failure, which is recorded in the run log.
