Categories — Subpages by Topic

One subpage per requested topic: gas prices, elections, culture, crypto, golf. Each shows the highest-dollar live events for that topic with the same ranking, chart, and order-book tools as the main dashboard. Topic matching is done live against GET /series (ticker, title, category, categories, tags) by keyword — heuristic and auditable in the UI, flagged as F4 on the Flagged for Review page because the API's exact category strings are not documented.
