KalshiDash2 — Kalshi Demo Dashboard

A live, interactive dashboard for the Kalshi demo exchange. It tracks the highest-dollar live events in five topics — gas prices, elections, culture, crypto, golf — follows them until they resolve (yes/no), and (with your own demo API keys) executes trades and analyzes performance. Every number on this site comes from a live API response or an official source link. Nothing is guessed.

Executive summary

PurposeCollect, organize, and analyze the highest-dollar live Kalshi demo events in gas prices, elections, culture, crypto, and golf; track them to resolution; trade and analyze performance on the demo account.
Data sourceKalshi demo REST API https://external-api.demo.kalshi.co/trade-api/v2 (recommended) and WebSocket wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2. Public market data needs no key. Source
Also supportedhttps://demo-api.kalshi.co/trade-api/v2 and wss://demo-api.kalshi.co/trade-api/ws/v2 — selectable in code (DEMO_BASE in assets/app.js). Source
AuthTrading/portfolio requires an API key ID + signed request (RSA-PSS or Ed25519). Keys are entered in the browser only and never stored in this repo. Source
Money safetyDemo uses mock funds; demo prices/behavior may not match production. No real money is involved. Source
Verification ruleEvery table row links an official source. Values that can't be confirmed are left blank and flagged — never inferred. See Verification and Flagged for Review.
