Executive summary

Objective Collect, organise and analyse the highest dollar-amount live events on the Kalshi demo exchange in five topics; track each event until resolution and record yes/no; trade the demo account and analyse results by trade category.
Data source Kalshi demo Trade API https://external-api.demo.kalshi.co/trade-api/v2 (recommended host) and WebSocket wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2. API environments
How data reaches the page A GitHub Actions workflow runs scripts/collect_kalshi.py every 15 minutes, commits the JSON it received to docs/data/, and the static page reads that same-origin snapshot. No browser cross-origin call is required to see data. Rate limits
Provenance Every snapshot file records the exact request URL and UTC time. The full request log, with HTTP status per call, is in data/meta.json.
Resolution tracking Settled markets are read with GET /markets?status=settled. Only rows whose result is exactly yes or no are counted as resolutions; scalar outcomes are labelled and excluded. Market settlement
Trading Orders are signed in the browser with the reader's own demo key (RSA-PSS) and sent to the demo host only. The current endpoint is POST /portfolio/events/orders. Create Order V2
Money safety The demo environment uses mock funds and its prices may not match production. No real money is involved anywhere in this site. Demo environment
Verification rule Every row of every table links an official source. A value that could not be confirmed is left blank and marked unverified. Nothing is inferred.
Known limitations No key lives in the repository, so account figures need your key. Ed25519 keys cannot be used from a browser. Chart windows beyond six hours are shorter than their labels. There is no gasoline-specific market category. All four are on the Flagged page.

What "highest dollar amount" means here

Kalshi does not publish a "dollar amount" metric. This site defines it as open_interest_fp × notional_value_dollars — both API fields — and prints that definition wherever the ranking appears. Contracts, not dollars, are used for the volume column. The definition is a choice, not an API fact, and is listed as flag F11 so you can change it.
