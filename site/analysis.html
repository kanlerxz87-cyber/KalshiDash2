Analysis & strategy

Descriptive statistics computed from the public snapshot, a framework for categorising trades once they exist, and the strategy ideas we can state but cannot yet test. No trade results exist yet, so no strategy has a demonstrated edge.

Portfolio performance and trade categories need authenticated demo-account data, which is not connected. Everything on this page is market-level, not account-level. See Portfolio & trades.

1. Market structure by topic (computed from snapshot)

Price buckets use the last traded YES price. "Longshot" = last price below 10¢, "Favourite" = above 90¢. Spread = yes ask − yes bid. Source for each row: the market endpoint in the Source column of its topic page.
