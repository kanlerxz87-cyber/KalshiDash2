Sources

Every factual claim on this site rests on one of the sources below. Each row names the official page, what the site uses it for, and how it was checked. A row is matched when its URL appears in Kalshi's own documentation index (llms.txt ↗), read when the page itself was read line by line during this build, and unverified when neither could be done — those rows are also listed on Flagged for review.

What is deliberately absent

No price, volume, balance or resolution value is transcribed into this repository. Every live figure is a response from the demo API fetched by your browser at the moment you look at it, which is why any row here can name an endpoint but never quote a number. When the API does not return a value the site shows n/a and flags it; it never fills the gap.
