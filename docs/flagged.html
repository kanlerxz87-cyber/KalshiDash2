How these were found

Every item below came from comparing code and claims against a primary source: Kalshi's published OpenAPI-derived documentation, the official kalshi-typescript SDK type definitions, or a live response from the demo API. Where a source contradicts itself — for example, a quick-start example that no longer matches the current request schema — both the doc page and the schema are linked, because the reader needs to see the disagreement, not a summary of it.
