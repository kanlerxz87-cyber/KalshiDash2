Demo portfolio & trade execution

Balance, positions, fills and order placement against your Kalshi demo account. Requests are signed in this browser tab. The private key is held in memory only, is never written to storage, and is never sent anywhere except the demo API.

Read this before adding a key

  • Use a demo API key created at demo.kalshi.co/account/profile ↗. Never paste a production key.
  • Demo credentials are separate from production and demo funds are mock only. Source ↗
  • Reloading the page drops the key from memory — that is deliberate. You will re-paste it to trade again.
  • Requests are signed against /trade-api/v2 + path with the query string stripped, RSA-PSS/SHA-256 (salt = 32) or Ed25519. Signing rules ↗
