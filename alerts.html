Live price alerts

A live alert stream over the five tracked topics on the Kalshi demo exchange. Every contract-price swing of $0.10 or more, in either direction, is posted into a scrolling chat. The second chat is the same feed filtered through the tradeability screen, so only the moves the model likes reach that column.

How a swing is measured

Kalshi publishes no "swing" field, so one is derived from two documented fields that every market carries: previous_price_dollars (the price before the exchange's last change) and last_price_dollars (the most recent trade price). A move qualifies when the absolute difference is at least the threshold. The same test is applied to the gap between two consecutive polls of this page, which catches moves the exchange's own reference has not rolled over yet.

What “the model likes” actually means

The shortlist chat is filtered by a tradeability screen: a transparent sum of points taken from documented market fields. It is deliberately not a probability model and it makes no claim about expected return — a price is not a probability unless someone says so. The screen is measured against settled demo markets on the Strategy Tester, where the hit rate of each signal is reported next to the market's own implied price.

Where to look when a contract jumps

Kalshi's event object carries settlement_sources — the official sources the exchange publishes for determining that market's outcome — together with the market's own rules. Those links appear under each chat message. They are the sources that decide the market; the API does not publish a news feed, so they are not presented as the confirmed cause of a move.
