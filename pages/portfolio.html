Blocked. The build sandbox has no Kalshi demo API key. Kalshi's API signs every trading and portfolio request with a key pair from the account page (API keys docs). The demo environment uses separate credentials from production (API environments).

What is needed to unblock

  1. A Kalshi demo account, created as described in Test in the demo environment.
  2. A demo API key created on the account profile page (kalshi.com/account/profile), with its key ID and private key. Keep the private key out of this repo.
  3. A decision on order size, topics allowed, and daily limits. These are safety settings for the demo account.
